A dark, moody block theme for tattoo studios, piercing parlours, and body-art collectives.

== Description ==

Ink St is a WordPress block theme made for tattoo studios and body-art parlours. Noir surfaces, a tattoo-flash red accent, and warm bone-ivory typography give every page the atmosphere of a real ink shop — equal parts underground gallery and late-night chair-side session.

The front page is a ready-made tattoo-studio landing page, and every section is also available as a separate pattern in the "Ink St" category:

* Hero — editorial split headline, booking buttons, full-height photo of an artist at work, studio-facts ticker
* Artists — resident artist roster with portraits, specialties, waitlist notes, and portfolio links
* Gallery — captioned portfolio mosaic (style + artist for every piece)
* Manifesto — studio story with key numbers
* Rates — flash-sheet price list with huge display prices
* Journal — latest posts for aftercare guides, artist spotlights, and studio news
* Visit — address, hours, contacts, social links, and a booking call-to-action

The header menu links straight to the front-page sections (Artists, Work, About, Rates, Journal); edit it in Appearance → Editor → Navigation.

Built entirely with native WordPress blocks. Works with the Site Editor out of the box — no page builder, no dependencies. Includes a light color style variation ("Bone Studio").

**Use cases:**
* Tattoo studio or tattoo parlour
* Piercing and body-modification studio
* Blackwork, fine-line, or traditional tattoo collective
* Tattoo artist personal portfolio
* Body-art, scarification, or microblading studio
* Any dark-aesthetic creative / counter-culture brand
